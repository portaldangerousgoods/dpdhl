# Documentos exigidos

Estes são os documentos que devem ser apresentados para o envio de Mercadorias Perigosas:

- FISPQ/FDS/ SDS (Ficha de Informações de Segurança de Produtos Químicos)
- Declaração de mercadorias perigosas (Shipper's Declaration), quando aplicável
- Declarações de transporte ou autorização de envio (para casos específicos)
- Documentação comercial padrão (nota fiscal, invoice)

⚠️ Todos os documentos devem ser revisados previamente pelo time de DG da DHL.
